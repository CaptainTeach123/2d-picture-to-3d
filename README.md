# 2D picture to 3D

A working playbook for rebuilding a picture as a 3D Blender scene and rendering it: what to check before a render, how
to review the result, and the lessons learned on each project so far.

Start with [RENDER_PLAYBOOK.md](RENDER_PLAYBOOK.md).

## How it is used

1. Read **Preflight** before every render.
2. Read **Review** after every render.
3. Read the topic sections before planning a new scene.
4. Add each new lesson as one line with a project tag, and correct or remove lines that turn out to be wrong.

Keep it short enough to read every time. Prefer editing an existing line to adding a near-duplicate.
